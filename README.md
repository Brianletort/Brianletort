## Research · ContextOS

The layer between what an AI system *can retrieve* and what it *actually
reasons with* is a compiler problem, and most architectures never made it
explicit. I publish that layer as **context compilation**.

- **[contextos](https://github.com/Brianletort/contextos)** — Context IR object
  model, JSON schema, lowering stage, and the CompileBench specification.
  Apache-2.0.
- Papers with DOIs: [context compilation](https://doi.org/10.5281/zenodo.19490059) ·
  [eight metrics — archived snapshot](https://doi.org/10.5281/zenodo.19472618) ·
  [compiler passes](https://doi.org/10.5281/zenodo.19546797) ·
  [paged context memory](https://doi.org/10.5281/zenodo.19546799) ·
  [quantized context](https://doi.org/10.5281/zenodo.19546801)

## Systems

- **[Frontier-Bridge](https://github.com/Brianletort/Frontier-Bridge)** —
  memory-hierarchy planning for giant MoE models on hardware you already own.
  Every published number is measured or absent; where the numbers don't work,
  the runbook says so.
- **[ai-infrastructure-reality-ledger](https://github.com/Brianletort/ai-infrastructure-reality-ledger)**
  — keeps infrastructure *proposals*, *construction*, and *operating capacity*
  as separate facts, each attached to evidence.
  [Live demo](https://ai-infrastructure-reality-ledger.vercel.app/launch) — public beta running a
  synthetic demonstration corpus.

## Privacy

- **[data-broker-eraser](https://github.com/Brianletort/data-broker-eraser)** —
  opt-out automation across 20 people-search brokers, re-run every 30 days
  because a one-time opt-out is theater. Runs on your machine; your data never
  enters an AI assistant's context. The README publishes the honest results
  table, including the brokers that blocked us.
